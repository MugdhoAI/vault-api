# Security Policy

Vault API is a learning and portfolio project and is not production ready. Do not use it to store real credentials or other sensitive data.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. If private vulnerability reporting is enabled for this repository, use GitHub's private reporting feature. Otherwise, contact the maintainer privately through GitHub and include a concise description, impact, and reproduction steps.

Do not include real passwords, tokens, encryption keys, or secret values in a report.

## Supported versions

Only the latest code on the default branch is considered for security fixes. No service level agreement or guaranteed response time is provided.
